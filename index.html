analyze-configuration-auditor

Audits system configurations (for example SSH and Apache) against security best practices and flags deviations, using YAML or JSON files for defining rules.

Open the repo Usage

The rules format

The first argument is a rules file in YAML or JSON. It must contain a top level rules list. Each rule is a mapping with four fields:

ida short identifier for the rule, for example SSH-001
descriptionwhat the rule requires, in plain text
checkthe exact text to search for in the system configuration file
severitythe severity label reported for the rule, for example High
rules:
  - id: SSH-001
    description: Root login is disabled
    check: "PermitRootLogin no"
    severity: High

Two rules of the audit

  • An empty rules list is an error: the tool exits nonzero and writes no report, because no audit was performed.
  • Lines that start with # are skipped, so a commented out setting does not count as a pass.

A shipped rule set for OpenSSH server settings is included as sshd_rules.yaml, covering PermitRootLogin, PasswordAuthentication, and PermitEmptyPasswords. Operators can supply their own rules files in the same format for other systems, such as Apache.

Install and usage

cd analyze-configuration-auditor
pip install -r requirements.txt

python3 main.py sshd_rules.yaml /etc/ssh/sshd_config

./analyze-configuration-auditor [params]

Parameters

-hshow help message and exit
-ono description provided in the source; listed that way rather than given a guessed job
-venable verbose logging

The files

main.py, the auditor itself. sshd_rules.yaml, the shipped OpenSSH rule set. requirements.txt, its dependencies (pandas and PyYAML). LICENSE, the MIT License. Full notes are in the repo README.
